⚡ Hubungkan Cloud Build Runner

        
      

      

        Mengapa Butuh Cloud Runner?

        Android OS (Android 11–14+) mewajibkan kompilasi biner resmi (AAPT2, D8, dan zipalign 4-byte) agar terhindar dari pesan "Ada Masalah saat mengurai paket" saat diinstal di HP fisik.


        Cloud Runner memanfaatkan GitHub Actions resmi untuk melakukan kompilasi biner resmi secara serverless, gratis tanpa VPS.
